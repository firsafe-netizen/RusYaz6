# Русский язык · 6 класс — приложение для Android 15+

Тренажёр по русскому языку для 6 класса: обучающие вопросы, упражнения с пропусками, тесты и **голосовые диктанты**
с настройкой скорости речи и темпа диктовки.

## Возможности

- **9 тем курса 6 класса**: повторение, лексика, фразеология, словообразование и орфография, существительное,
  прилагательное, числительное, местоимение, глагол.
- **Обучающие вопросы** — карточки «вопрос — ответ» с режимом самопроверки («Знаю» / «Повторить позже») и списком.
- **Упражнения** — вписать букву или выбрать вариант; проверка с подсветкой ошибок и правильными ответами.
- **Тесты** — сразу показывают верный ответ и пояснение, в конце — «работа над ошибками» и оценка.
- **Диктанты голосом** (встроенный синтезатор речи Android, работает без интернета):
  - как на уроке: чтение всего текста → каждое предложение по частям с повтором и паузой на запись → проверочное чтение;
  - настраиваются **скорость речи**, **тон голоса**, **темп** (секунд на запись слова), пауза между предложениями,
    длина частей, число повторов, выбор голоса; готовые режимы «Медленно / Обычно / Быстро»;
  - кнопки «назад», «повторить», «дальше», ползунок перехода, показать/скрыть текущую фразу;
  - **проверка**: ученик вводит написанное, приложение сравнивает с образцом, подсвечивает ошибки
    и ставит примерную оценку.
- **Свои материалы**: кнопка «Добавить» — диктант, тест, упражнение или вопрос; импорт/экспорт файлов JSON.
- Сохранение лучших результатов, тёмная тема, цвета Material You.

### Про задания из сборника Т. В. Шкляровой

Тексты сборника защищены авторским правом, поэтому в приложение встроены **собственные** задания по темам
программы 6 класса. Упражнения и диктанты из своего экземпляра сборника можно внести самостоятельно:

- в приложении: «Добавить» → выбрать раздел и тип → вставить текст;
- или заполнить файл `primer_import.json` (шаблон лежит в корне проекта) и загрузить через меню ⋮ → «Импорт».

Формат пропусков в упражнениях: `к{о}рова` — ученик вписывает букву; `р{а|о}стение` — выбор, первый вариант правильный;
`Сем{|ь}надцать` — правильный ответ «ничего не писать».

## Как получить APK

### Вариант 1 — GitHub Actions (без установки программ)

1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки
   (кнопка «Add file → Upload files», папку `.github` тоже нужно загрузить).
2. Откройте вкладку **Actions** — сборка «Сборка APK» запустится сама (или нажмите «Run workflow»).
3. Через 5–8 минут откройте завершённый запуск и скачайте архив **RusYaz6-apk** внизу страницы.
4. Распакуйте и перенесите `RusYaz6.apk` на телефон, откройте его и разрешите установку из этого источника.

### Вариант 2 — Android Studio

Откройте папку проекта в Android Studio (Ladybug или новее) → дождитесь синхронизации Gradle →
**Build → Build App Bundle(s) / APK(s) → Build APK(s)**. Готовый файл: `app/build/outputs/apk/`.

Из командной строки: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.

> Release-сборка подписана отладочным ключом, чтобы её можно было сразу установить. Для публикации в Google Play
> настройте собственный ключ в `app/build.gradle.kts`.

## Настройка голоса на телефоне

Нужен синтезатор речи с русским языком, обычно это «Распознавание и синтез речи от Google».
Настройки → Специальные возможности → Синтез речи → выбрать движок Google → Язык: Русский → скачать голос.
Если голос не установлен, приложение покажет кнопку для его установки.

## Технические детали

- Kotlin, Jetpack Compose (Material 3), Navigation Compose; minSdk / targetSdk 35 (Android 15).
- Встроенные материалы: `app/src/main/assets/content.json`. Материалы пользователя хранятся в
  `files/user_content.json` внутри приложения.
- Озвучка: `tts/DictationPlayer.kt` (TextToSpeech + корутины), разбиение на части: `tts/DictationPlan.kt`.
- Проверка диктанта: `data/TextCheck.kt` (сравнение по словам и знакам препинания).
